# Myanmar Astro Horo - Python Version
# မြန်မာ ရိုးရာ ဇာတာဖွဲ့ - Python ဗားရှင်း

## Description

This is a complete Python rewrite of the Myanmar Astronomy Horoscope App, originally developed in Visual Basic 6 by Kaung Paing in 2002/2003. The application is based on the ancient astronomical theory of "Surya Siddhanta" (သူရိယသိဒ္ဓန္တ).

## Features

- Complete astronomical calculations based on Surya Siddhanta
- Myanmar calendar system implementation
- Horoscope generation with traditional Myanmar astrology
- City database with geographical coordinates
- Nakshatra (နက္ခတ်) calculations
- Planetary position calculations
- Traditional Myanmar time system

## Installation

```bash
pip install -r requirements.txt
python main.py
```

## Project Structure

- `main.py` - Main application entry point
- `core/` - Core astronomical calculation modules
  - `astronomical_calculations.py` - Main astronomical functions
  - `calendar_system.py` - Myanmar calendar system
  - `planetary_calculations.py` - Planetary position calculations
  - `nakshatra_system.py` - Nakshatra calculations
  - `time_system.py` - Traditional time calculations
- `data/` - Data files and mappings
  - `cities.py` - City database with coordinates
  - `myanmar_data.py` - Myanmar-specific astronomical data
- `gui/` - User interface modules
  - `main_window.py` - Main application window
  - `horoscope_form.py` - Horoscope generation interface
- `utils/` - Utility functions
  - `converters.py` - Unit conversion utilities
  - `validators.py` - Input validation
